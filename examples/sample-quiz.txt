"""QUESTION"""
What does this Python code print?
"""CODE"""
total = 1
for value in range(3):
    total += value
print(total)
"""CODE"""
"""CHOICES"""
A: 3
B: 4
C: 5
D: 6
"""ANSWER"""
B
